# Info
Alle tegninger i spillet er originale og laget for hånd av medlemmene på gruppa. Dyrene kommer fra den vietnamesiske stjernetegn og spillet tar inspirasjon fra vietnamesisk nyttår. Temaet "Growth" er inkorperert gjennom de voksende kulene i spillet. Du starter med det minste dyret, rotte, og kan jobbe deg helt opp til en drage, som er den største.
